# Inventory Control Challenge

Build an automated test solution for an inventory application.

- Users can view inventory records, search by name, and filter by category.
- Users can add an item with a name, category, and positive quantity.
- The API supports listing, creating, updating, and deleting inventory records.
- Invalid requests must return a client error with a useful message.
- The critical user journey must work in a desktop browser and remain usable at a mobile viewport.
- The primary API response should complete within 500 ms during normal use.

Required evidence: functional UI coverage, API contract coverage, negative validation, network diagnostics, and a traceability matrix.
